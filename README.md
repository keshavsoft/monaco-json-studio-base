# monaco-json-studio-base

Shared base engine, region builders (`header/`, `body/`, `footer/`), and browser Monaco runtime for `monaco-json-studio-single`, `monaco-json-studio-double`, and `monaco-json-studio-triple`.

## Install

```bash
npm install monaco-json-studio-base
```

## Usage

```js
import { generateStudio } from 'monaco-json-studio-base';
```
