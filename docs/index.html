monaco-json-studio-base

The shared primitive engine and browser runtime powering monaco-json-studio-single, double, and triple.

npm Package GitHub Repo Suite Story & Architecture

The Story

Each pane is split into header/, body/, and footer/ regions in src/v1/ and assets/v1/. DOM events use dom-primitive-bindings (bindings.json + actions.js), while Monaco callbacks update cursor state.

Example

import { generateStudio } from 'monaco-json-studio-base';

generateStudio({
  title: 'Custom Studio',
  outputDir: './my-studio',
  panes: [{ key: 'pane1', label: 'Pane 1', header: 'file-picker', body: 'monaco', footer: 'cursor' }]
});
